瀏覽器安全性協定阻擋 (CORS Restrict)

由於您是直接點擊雙擊打開網頁 (網址列為 file://...)，瀏覽器出於沙箱安全考量，將無法使用 Fetch API 去讀取本地的 Markdown 檔案。

解決方案：

  • 推薦：將專案目錄上傳至 GitHub Pages 後即可完美動態載入！
  • 本地預覽：請用 VS Code 的 Live Server 插件，或在該目錄執行命令 npx serve 或 python -m http.server，在 localhost 環境下瀏覽。
